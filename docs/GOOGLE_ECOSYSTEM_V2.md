# Google ecosystem incorporado en V2

## Obligatorio V1

- Gemini API: núcleo de agentes.
- Google Auth/Gmail login: ingreso simple.
- Google Calendar: seguimiento y reinspecciones.
- Google Maps: ubicación de empresas, bases e inspecciones.

## Preparado sin bloquear V1

- Gmail API: envío de PDF y recordatorios cuando el usuario autorice permisos.
- Cloud Run: backend de agentes cuando convenga salir de Vercel-only.
- Cloud Storage: fotos, PDFs y evidencia.
- Cloud Logging: trazabilidad técnica.
- Vertex AI: evaluación enterprise/prompt governance futuro.
- GA4: tracking complementario al tracking interno.

## Regla

No se agregan servicios por logo. Cada servicio debe demostrar venta, retención, evidencia o escalabilidad.
