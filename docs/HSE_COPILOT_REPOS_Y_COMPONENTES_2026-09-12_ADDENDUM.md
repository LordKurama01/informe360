# HSE Copilot — Addendum de repos/componentes (2026-09-12)

## ADOPTAR / INTEGRAR

- `SafetyMP/Autonomous-EHS-Management` — Apache-2.0. Donante de patrones de dominio EHS: observaciones, CAPA, evidencia, auditoría, cierres y estados.
- `nigdanil/AuditM-Field` — MIT. Referencia directa para captura de campo, evidencia fotográfica, anotación y offline básico.
