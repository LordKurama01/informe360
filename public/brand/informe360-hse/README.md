# Informe360 HSE — Brand Assets

Activos oficiales del concepto HSE orientado a operaciones petroleras.

## Archivos

### PNG
- `informe360-hse-color.png` — versión principal a color.
- `informe360-hse-claro.png` — versión clara.
- `informe360-hse-oscuro.png` — versión para fondos oscuros.
- `informe360-hse-transparente.png` — versión sin fondo.

### SVG
- `informe360-hse-color.svg` — versión principal a color sobre fondo blanco.
- `informe360-hse-claro.svg` — versión para superficies claras.
- `informe360-hse-oscuro.svg` — versión para interfaces o fondos oscuros.
- `informe360-hse-sin-fondo.svg` — versión vectorial transparente.

## Uso recomendado

En Next.js pueden utilizarse directamente desde `/brand/informe360-hse/<archivo>` porque están dentro de `public/`.

Ejemplo:

```tsx
<img src="/brand/informe360-hse/informe360-hse-sin-fondo.svg" alt="Informe360 HSE" />
```

Identidad visual: casco de seguridad + torre de perforación + movimiento 360°, sin elementos vegetales. Paleta principal: carbón/navy, blanco/acero y naranja industrial.
